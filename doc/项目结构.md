# BookerEpubTool 代码结构

iBooker/ApacheCN 知识库抓取工具。

命令行入口两个：`BookerEpubTool` 与 `epub-tool`，均映射到 `BookerEpubTool.__main__:main`（见 pyproject.toml 的 `[project.scripts]`），即 `python -m BookerEpubTool` 也可直接运行。`__main__.py` 注册 `comp`、`toc`、`fmt`、`mkds`、`title`、`trans`、`crawl` 七个子命令，其中 `toc.py` 还统括 `ext-chs` / `ext-htmls` / `ext-pics` / `sel-nocd`；`fmt.py` 对应 `fmt-para`；`title.py` 对应 `add-title`。

代码全部位于 `BookerEpubTool/` 包内，按职责分为八类模块：

## 1. 入口与命令注册

+ `__main__.py` — 唯一 CLI 入口。构建顶层 `argparse` 解析器（prog="BookerEpubTool"，含 `-m/--model`、`-k/--key`、`-H/--host`、`-r/--retry`、`-tm/--temp`、`-D/--debug` 等公共 LLM 参数，注意 `-m` 在 `trans` 之前表示模型名，在 `trans` 之后则是 `--fmt-mode`），注册上述七个子命令，最后按 `args.func(args)` 派发。
+ `__init__.py` — 包元信息（`__version__` = 2026.3.25.0，作者 wizardforcel，SATA 协议）。

## 2. 共享基础设施

+ `util.py` — EPUB 核心读写工具，跨命令复用：EPUB zip 包读写（`read_zip`/`write_zip`）、OPF/NCX 解析（`parse_opf`/`parse_ncx`/`read_opf_ncx`）、目录导航（`get_nav_lv`）、EPUB → HTML 转换（`epub2html_pandoc`）、文本与模型缓存（`read_text`/`write_text`、`read_yaml_model`/`write_yaml_model`、`json_dump_model`）、`md5`/`gen_objs_md5`/`extname`/`fname_escape` 等。
+ `openai.py` — LLM 客户端层：`OpenAIClient` 类封装 `request_retry` / `call_llm` / `call_llm_retry`；`ToolsMixin` 工具型命令混入；`base_schema`/`func_schema`/`params_schema`/`model_schema`/`str_list_schema`/`str_str_map_schema` 等 Schema 构造助手；`dispatch_tools` 按模型返回的 tool call 分发到工具方法。
+ `gen_epub.py` — EPUB 打包库：`gen_epub_aio`（一章一文件）与 `gen_epub_paging`（分页打包，支持 `limit` 大小限制），供抓取类命令复用。

## 3. EPUB 图片压缩命令（comp）

+ `comp.py` — `comp` 子命令：`compress` 优化 EPUB 内所有图片并原位覆盖写入，支持 `quant`（pngquant 量化）/`grid`/`trunc`（截断至 N 色）/`thres` 四种压缩模式及 `-c/--color` 颜色数参数，`reg_subparser` 注册。

## 4. EPUB 查看与导出命令

+ `toc.py` — `toc`（打印目录树，可按级别/正则过滤）、`ext-chs`（按目录条目拆分章节并合并导出独立 HTML，支持 `-s`/`-e` 范围、`-a` 全合并）、`ext-htmls`（导出版内全部 HTML）、`ext-pics`（导出版内全部图片）、`sel-nocd`（筛选不含 `<code>` 的 EPUB 并移动到输出目录）；包含 `filter_toc`、`get_toc`、`get_html_body`、`ext_chs`、`ext_htmls`、`ext_pics`、`select_nocode` 与 `reg_subparser`。

## 5. 格式化与数据集命令

+ `fmt.py` — `fmt-para` 子命令：`format_para` 把过短段落合并到下一段（原位覆盖写入），`fmt_oreilly`/`fmt_packt`/`fmt_apress` 按出版社预处理 HTML，另有 `fmt_zh`、`fmt_link`、`fmt_img`、`fmt_en_zh_gap` 等排版函数，`reg_subparser` 注册。
+ `mkds.py` — `mkds` 子命令：`make_dataset` 逐章取标题和段落，输出 `{书名}.yaml` 细粒度文本数据集，支持 `-t/--title`、`-p/--paras` CSS 选择器与 `-w/--whole` 整体拆分，`reg_subparser` 注册。
+ `title.py` — `add-title` 子命令：`add_title` 对每个目录条目，若章节正文首元素与目录标题不一致则在头部插入 `<h1>`，`reg_subparser` 注册。

## 6. 翻译命令（trans）

+ `trans.py` — `trans` 子命令：`TransDispatcher` 按章节多线程分块翻译英文 EPUB 为中文 Markdown，分 8 步（初始化元数据→转 HTML/MD→导出图片→排版+翻译→修正目录→分章节→生成 README/SUMMARY），中间产物缓存到 `{书名}/asset/`，断点续跑不重复消耗 API；`trans_file_safe` 单文件安全入口，`reg_subparser` 注册。
+ `trans_agent.py` — `TranslatorAgent` 与 `TranslatorSplitAgent`（继承 `ResplitAgent`）智能体：负责章节边界判断与逐段/逐块调用 LLM 翻译。
+ `trans_models.py` — 翻译与目录修正的 Pydantic 模型：`Meta`、`Chunk`、`TocExtResult`、`TocLevelChange`、`TocTextChange`、`TocChanges`。
+ `resplit_agent.py` — `ResplitAgent`：基于 GPT 识别章节边界并拆分为章的智能体。
+ `resplit_models.py` — 拆分判断的 Pydantic 模型：`CheckSplitLineResult`/`CheckSplitResult`、`ChapterSplitLineResult`/`ChapterSplitResult`、`JudgeSplitAccResult`/`JudgeSplitRejResult`/`JudgeSplitResult`。

## 7. 文本清洗工具

+ `clean_heading.py` — Markdown 标题清洗工具：`clean_handle`（按文件/目录批量处理，多线程池）、`clean_md_llm`（分块调用 LLM 清洗）、`clean_file`，暴露 `reg_subparser`（随包提供，与包同级可独立使用）。
+ `clean_heading_pmt.py` / `clean_heading_models.py` — 清洗提示词模板（`{XXX}_PMT`）与 Pydantic 模型 `CleanHeadingLineResult`。

## 8. 网站抓取命令（crawl）

+ `crawl.py` — `crawl` 子命令：`CrawlOrchestrator` 整站抓取并生成 EPUB，页面线程池与图片线程池并发，同步 EpubCrawler 全局配置（UA、Cookie、超时、重试、图片优化模式等），`crawl` 入口，`reg_subparser` 注册。
+ `crawl_agent.py` — `CrawlAgent` 智能体：逐站点调用 LLM 抓取文章，产出 `asset/` 目录中的中间产物。
+ `crawl_models.py` — 抓取数据模型：`AnchorLink`（锚点链接）、`TocItem`（目录项）、`ArticleResult`（文章结果）。
+ `crawl_img.py` — 图片下载与优化：`tr_download_img`/`tr_download_img_safe` 线程安全下载、`process_img` 处理 HTML 中图片、`opti_img`（`quant`/`grid`/`trunc`/`thres` 模式压缩）、`load_img`/`save_img` 按哈希缓存。

## 9. 资源目录与测试

+ `assets/` — EPUB 资源与 Jinja2 模板：`Style.css`、`article.j2`、`content.j2`、`toc.j2`、`container.xml`、`mimetype`。
+ `tests/` — pytest 冒烟测试：`test_crawl_smoke.py`、`test_trans_smoke.py`（`.pytest_cache/` 表明已有测试运行）。
